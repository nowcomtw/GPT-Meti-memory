# 版本紀錄

## 0.2.1（本機交付 2026-10-22）

新增 7 個一般顯示欄位、4 個 Odin 描述欄位、18 個資源顯示覆寫及 25 個執行期字串。修正回收站、人口成長對話、冶金廠研究、威脅等級、FTL 與動態按鈕漏翻。Construction 的查找名稱與兩個 UXML 鏡像同步處理，研究操作實測通過。

## 0.2.0

擴充 UI Toolkit、一般資料、Odin 劇情與任務顯示欄位、經定位的 section titles 及執行期字串。該階段有 187 個已套用執行期字串；0.2.1 最終清單共 212 個。

## 0.1.2

建立繁中 TextCore 字型後備、早期顯示文字與固定索引 metadata 字串修補基底。

## 方案封存（2026-10-25）

整理至 GitHub 的 STARHOME 子資料夾：翻譯全量對照、原理、歷史原碼、安裝還原參考、版本 hash 與原有驗證摘要。不含完整安裝 ZIP、遊戲資產、存檔或工具二進位；沒有新增遊玩驗收結論。
