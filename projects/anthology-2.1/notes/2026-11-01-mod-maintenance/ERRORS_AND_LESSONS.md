# 錯誤、失誤與處理紀錄

日期：2026-11-01。這是可追溯的問題紀錄，不是所有問題已解決的宣告。已知事實、支持性推論與未完成分開記載。

| 項目 | 發生什麼事／為何有問題 | 處理與目前邊界 |
|---|---|---|
| 材料數量單位誤解 | 把材料份數與整盒／整瓶物件混用；玩家指出每種曾達 500，後續最高每種 250 盒仍過量。 | 改為每種 3／4／5 盒／瓶，清楚記每盒 10／15／5 份；仍須控制整個世界物件。 |
| 未經需求確認擴大商人控制 | 以全世界物件數設停補／排隊／清貨，連其他商品也受影響；使用者需要正常買東西。 | 該保護不能當預設；最新低量表在 guard 兩入口交回原補貨，未加新停補機制。 |
| 將閃退過早歸因商人 | AMMO_S 封包長度異常、ID 重用及大量補貨有關聯證據，沒有同一 Fatal 的完整重現。 | 寫為支持性推論；後續 Not enough IDs 是另一個明確錯誤。不能把全部問題都歸咎單一 MOD。 |
| 不存在的 Lua API | 錯誤圖有 `meti_ammo_all_native.script:28` 呼叫不存在的 `r_u32_ex`。 | 這是測試／診斷腳本自身的 API 假設錯誤，不能算配方原生失敗。後續有有限配方測試記錄；不得重新帶入該失敗腳本。 |
| 測試環境與接口過度擴張 | 為小量補貨建立大量隔離、接口與人工進店流程，耗時、耗空間，還反覆修測試環境。 | 使用者已明確要求停止此模式；後續直接本體、最小備份、自行遊玩驗收。沒有保證不搶桌面就不啟動遊戲。 |
| 忽略使用者的實測 | 玩家已確認同一 NPC 重影，仍追問是不是不同人、是否安裝榴彈等，拖延真正排查。 | 玩家已交代的事實作為測試前提；提出可檢驗原因，不反覆否定／重問相同條件。 |
| 熱像重影修錯層 | 顏色與亮度調整不能修復主畫面／鏡內投影不同；倍鏡才出現一大一小輪廓。 | 改同場景座標與單次熱像合成後，玩家附圖確認成功；不能外推全部鏡具已驗。 |
| 倍鏡冷背景變糊／顆粒過多 | 原生熱像冷底再轉綠、增亮或重複處理，無法保留實景材質。 | 最終改回真實場景背景；不以降噪補丁宣稱已恢復正常材質。 |
| Shader 相容參數錯誤 | `pfx_volumetric_light.ps` 的 `Texture2DMS.SampleLevel` 曾報 X3088；還曾寫入不合法 `r3_msaa off`。 | 合法 MSAA 關閉值是 `st_opt_off`；使用者另關體積光後能進遊戲。這不代表選單閃退與 FPS 問題已排除。 |
| Ctrl+V 沒隔開所有回呼 | 鍵盤修飾鍵轉送不能阻止另一腳本仍讀 V，夜視亮度會被改。 | 最新 B 榴彈，取消 Ctrl+V 轉送及 B 夜視亮度；待玩家實測完整組合。 |
| 生理需求範圍誤解 | 使用者只要三種需求慢一半，方案卻一度涉及睡眠檢查時間／睡覺跳時。 | 保留 `sleep_chk=300`，撤回 600；只調三需求，不更動其他數值。 |
| 繁簡與缺字 | 整合包字型主要是簡中，新增繁體提示導致準、備、請等缺字；字串／XML 存在不能證明可顯示。 | 新遊戲文本用簡體；局部替字不宣稱補齊全字庫。整體仍可能有原包或其他模組未譯。 |
| 同圖預熱誤判落點 | 正常 NPC 站位與導航節點差異被當不合法，近距離也被取消。 | 0.1.1 曾修此點；不是「太近不能傳送」。最終還需合法落點檢查。 |
| 同圖預熱過度等待 | 全 ID 分批掃描＋周邊全部上線門檻，使近距離等待很久後讀圖。 | 0.1.2：已就緒即傳；其餘短試約 1 秒，超時原讀圖。使用者拒絕 30／10 秒；本版尚待遊玩驗收。 |
| 超時處理方向一度錯誤 | 曾提出超時取消，使用者指定要「超時轉圖傳送」。 | 最終程式及文字已採讀圖 fallback；非法資料／Esc／走離原地仍可取消。 |
| RVR 500 取出後鎖定 | 玩家回報首次成功後「未就緒或已鎖定」；生成彈藥回傳值／ID 假設不符。 | 明確使用 `_g.create_ammo` 的回傳列表並檢查物件／ID；另修大彈盒計數。後續完整遊戲內驗收待定。 |
| 以檔案／模型 PASS 代替遊玩成功 | 語法、雜湊、有限模型、少數商人隔離通過，都沒有涵蓋所有商人、地圖與存讀檔。 | 報告必須列範圍及 NOT_RUN；只有實際玩家回報才提升對應場景狀態。 |
| 版本與回退說明漂移 | 資料夾 v0.1.0 實際內容多次更新；功能主檔由相容層覆寫，取消原模組可能沒作用。 | 用實際內容版本、provider／receipt 與單檔回退；不隨意改名或刪除相容層。舊完整 modlist 不能覆蓋日後設定。 |
| 物件數分類口徑漂移 | 舊商人／服務分組摘要比詳細分類少 7，容易誤判庫存變化。 | 兩個快照用同一 section 規則重算皆 2,252，附註這不是實際商品數。 |
| 工具／測試失敗不得隱藏 | 曾用 WindowsApps `python` 別名無有效結果；現有 Python 沒有 lupa，未找到可用 Lua parser。 | 改用已知 runtime；本次快速旅行只做 XML／安裝完整性檢查，不宣稱 Lua 編譯或原生測試通過，不為此再安裝工具。 |

未結案：選單／MCM 閃退、偶發 FPS、部分字體／翻譯、陣地 AI 卡住、所有新物品 RVR 存領、多種倍鏡與新快速旅行跨場景驗收。沒有用這份文件授權繼續開發或全面研究。
