# Anthology 2.1 載入速度與 FPS 查證

日期：2026-10-27（Asia/Taipei）。
狀態：唯讀查證完成；本次性能研究未改遊戲、設定、存檔，未啟動遊戲。

## 環境與問題

正式遊戲使用 AnomalyDX11AVX、MO2 Profile `Anthology 2.1 Standart Стандарт`，啟動項 `Anomaly (DX11-AVX)`。

目前引擎 SHA-256：
`6bbc9b630fa496f9d0c31eb3864b6ed29fe9d8cf0d35302ba756e462bdb5ff9e`。

日誌標示 MT-TEST 2026.09.30，並有 Anthology v86 的原生優化紀錄。整合包公開引擎渠道此次讀到的固定版本是 2026.7.20，未證實與本機 EXE 相同；不可直接覆蓋。

正式遊戲與 MO2 資源在 D 槽，磁碟查讀確認為 SATA HDD。C 槽為 NVMe SSD，當次約有 451.2 GiB 可用。使用者明確決定暫不搬移至系統 SSD。

其他 load-session 子階段可能互相重疊，不可把每個數字都加成獨立等待時間。55,167 個載入物件是整個存檔相關紀錄，不等於玩家背包有 55,167 件物品。

硬碟小檔讀取與資源初始化是最高優先瓶頸方向；尚未做 SSD 對照，不能把全部時間都唯一歸因於 HDD，也不能承諾搬移後的秒數。

## 已存在的設定與優化

- `r__clear_resources_on_unload off`
- `r__no_ram_textures off`
- `load_world_warmup_ms 0`
- `mt_load_spawn_decode 0`
- `mt_ui 1`
- 啟動命令包含 `-smap2048 -dbg -prefetch_sounds`。

日誌已顯示 parallel、save-prefetch、spawn-prefetch、level-cache、sparse precache 等機制。沒有因而全面切換 MT、清空快取或再安裝同類優化。

保留資源池會增加 RAM／VRAM 使用的可能性；若空間不足，可能導致換入換出。磁碟著色器快取占用空間，更新引擎或 shader 後有時需針對不相容項重建；不等於平常應反覆清除。

僅移除 `-prefetch_sounds` 的可評估代價，是把部分資源準備延後至第一次需要聲音時，HDD 上可能出現首次使用停頓。尚未測試本機效果。全面停用模型／材質預讀的 `-noprefetch` 是另一件事，不能混為同一個安全開關。未確認目前客製引擎行為前不套用。

## FPS 與背包的已確認現象

- 未找到 Fatal、`LUA error:` 或 `lua_pcall_failed`；末尾有引擎關閉日誌紀錄，未另做 GUI 退出驗收。
- 背包／交易建立的幾筆計時約 1.127、1.161、1.627、2.150 秒，主要涉及容器重新建立。另有快速返回記錄，不能當成完整重建加速成功。
- 第 15724 行進入交易介面；第 15730／15733 行原生 Present／frame profile 有約 2.8 秒長幀。
- 介面開啟期間，某 300 幀窗口平均 total 77.03 ms、frame 59.04 ms、render 17.75 ms。77.03 ms 換算約 13 FPS，僅指該窗口，不是全程平均。
- 自製 `Meti_InventoryCounterBatch_v0.1.0_TRIAL` 內部 0.5.0 增量流程，出現 4 次 `fallback snapshot unavailable: read error`（第 4830、15228、15318、15806 行），退回原完整處理。不能把跨開啟重用當成當次正常生效。
- 其他 axis_cache、計數合併有命中，不等於整個優化完全無效。
- `inc_snapshot` 約第 251 行開始；392–395 行未保存原始 pcall 錯誤內容。無法僅由此判定是哪個物品或欄位拋錯。
- texture-residency 的 pressure 所見皆為 0；不能據此排除全部 GPU 瓶頸。
- 日誌有 GC 10–20 ms 的被列出樣本；存在背景 GC，不能把每筆時間直接當主執行緒停頓，亦不能宣布記憶體洩漏。
- 讀檔、換圖、UI、暫停及退出混在 profile 中；沒有把所有長幀都當成戰鬥掉幀。

物品組合設定、動態音樂的不存在回呼、夜視 MCM 路徑與路線點任務警告仍存在。未證明它們是持續 FPS 波動的原因。

## 後續修改依據

1. 使用者若重啟背包工作，優先定位自製增量快照的原始例外，保留原回退和物件有效性保護，不任意清空背包或取消全部排序。
2. 一般走路／戰鬥波動需要與動作對齊的有限資料；UI 問題不能涵蓋所有場景。
3. 若日後同意搬至 SSD，需同時處理本體與 MO2 資源、核對所有路徑並保留當前自製補丁；不經自動更新覆蓋現有成果。
4. PR #730 提供材質 metadata 的 LTX 支援及平行 THM 讀取的安全修正，不是已證實適用本機的一鍵加速 MOD；本輪不換引擎。

最新使用者決定：維持現況，保留資料供後續 MOD 製作，暫停進一步性能調整。
